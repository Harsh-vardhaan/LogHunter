# Security Policy

## Authorized Defensive Use

LogHunter is an offline defensive analysis tool. Use it only with logs you own or are explicitly authorized to access. Protect operational logs according to your organization’s data-handling requirements.

LogHunter does not perform exploitation, network scanning, credential attacks, authentication attempts, automatic blocking, firewall changes, account actions, or active response. Findings are heuristics and must not be treated as proof of compromise or malicious intent.

## Supported Releases

Security fixes are intended for the latest released version. Version 1.0.0 is currently being prepared and has not been tagged or released from this branch.

## Reporting a Vulnerability

Do not include sensitive logs, credentials, tokens, or personal data in a public issue. Use the repository’s private GitHub Security Advisory reporting flow when available. If private reporting is unavailable, open a minimal public issue requesting a private contact channel without disclosing exploit details.

Please include the affected version, reproducible steps using synthetic data, impact, and suggested mitigation when practical.
